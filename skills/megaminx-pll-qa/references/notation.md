# 手順の記法

記事の手順と、スクリプトの `--alg`・`--setup` が読む記法(megaminx-image の記法)。

| 記法                              | 意味                                                                                         |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| `U F R L BR BL DR DL DBR DBL B D` | 12 の面。`X` は面 X を時計回り(その面から見て)に 72° 回す                                    |
| `X'`                              | 反時計回りに 72°                                                                             |
| `X2`                              | 時計回りに 144°                                                                              |
| `X2'`, `X'2`                      | 反時計回りに 144°                                                                            |
| `X3`, `X4`, …                     | 回数は 5 で割った余りで読む(`R5` は何もしない)                                               |
| `y`                               | パズル全体を U のまわりに、`U` と同じ向きに回す(`y'`・`y2` なども)                           |
| `( … )`                           | まとまり。後ろに回数や `'` を付けられる:`(R U R' U')2`、`(R U)'`(逆の手順)。入れ子にもできる |

- 大文字と小文字は区別しない(`br` = `BR`)。`DFR` と `DFL` は `DR` と `DL` の別名
- WCA のスクランブルの記法(`R++ D--`)には対応していない
- 記事の手順の先頭の `(U)`・`(U2')` などの括弧は、手順を回し始める前の AUF(上面の向きを合わせる回転)
- `--alg` は「その手順で揃うケース」、`--setup` は「揃った状態にその手順を回した状態」。PLL の手順をそのまま調べるなら `--alg`
