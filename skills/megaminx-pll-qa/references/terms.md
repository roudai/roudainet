# 判断の用語

記事(roudai.net の Megaminx PLL)で使う、PLL の判断の言葉の定義。
番号の書き方(`L(k)`・`E(k)`・`R(k)`、頂点)は `stickers.md`。`scripts/lib.mjs` の `features()` はこの定義どおりに探す。
基礎知識のタブの説明そのものは `article/basics.md`。

## 本物

| 用語                   | 定義                                                                                                                                                                                                                                                                                  | show(面 k の場合)                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| ペア(2x1)              | 1 つの面で、エッジと隣のコーナーの色が同じ。面全体が揃っているときはバーと呼ぶ                                                                                                                                                                                                        | 右側なら `E(k), R(k), L(k+1)`                      |
| バー(3x1)              | 1 つの面の 3 枚(コーナー・エッジ・コーナー)の色が同じ                                                                                                                                                                                                                                 | `R(k-1), L(k), E(k), R(k), L(k+1)`                 |
| ブロック(2x2)          | 隣り合う 2 つの面で、`E(k) = R(k)` かつ `L(k+1) = E(k+1)`。間のコーナーごと揃っている                                                                                                                                                                                                 | `E(k), R(k), L(k+1), E(k+1)`                       |
| 3x2ブロック            | バーの両側にブロックがある(バーの面と、その両隣の面のエッジまで揃う)                                                                                                                                                                                                                  | `E(k-1), R(k-1), L(k), E(k), R(k), L(k+1), E(k+1)` |
| Jブロック・逆Jブロック | バーと、その片側の隣の面まで続くブロック。ブロックが面 k-1 側にあれば **Jブロック**(例:J2+ の右上の面のバーと右下の面へのブロック)、面 k+1 側にあれば **逆Jブロック**。両側なら 3x2ブロック、ブロックの先もバーなら 2 つのバーが繋がった形(U1 など)で、どちらも Jブロックとは呼ばない | バーの 5 枚と、ブロックの側の隣の面のエッジ        |
| ヘッドライト           | 1 つの面で、両側のコーナーが同じ色、エッジだけが違う色(`L = R ≠ E`)                                                                                                                                                                                                                   | バーと同じ 5 枚                                    |
| Rブロック              | ヘッドライトの片方のコーナーが、隣の面のエッジとペアになっている。ペアがヘッドライトの左にあれば**左Rブロック**(`E(k-1) = R(k-1)`)、右にあれば**右Rブロック**(`L(k+1) = E(k+1)`)。記事では「左がペアのRブロック」のようにも言う                                                       | 右なら `R(k-1), L(k), E(k), R(k), L(k+1), E(k+1)`  |
| Yペア                  | 1 つのコーナー(頂点 k+1)を挟んで、面 k の左側と面 k+1 の右側にペアがある(2 つのペアは外向き)。どちらもブロック・バーの一部でない。記事の Y の段階で決めた言葉                                                                                                                         | `R(k-1), L(k), E(k), E(k+1), R(k+1), L(k+2)`       |

## 記事の数え方・言い方

- **ブロックの中のペアは、ペアと数えない**(ブロックと呼ぶ)。A2・W・Y1 を「ペアが 4 つ」とは言わない。
  `features.mjs` は、そのペアに「(ブロックの中)」と印を付け、外のペアの数を出す。Rブロックの中のペアは、外のペアとして数える
- **Rブロックの中のヘッドライト**:記事は、ペアと組んだヘッドライトを「Rブロック」と呼び、ヘッドライトとは数えない(B・R・P)。
  `features.mjs`・`search.mjs` は、Rブロックの一部のヘッドライトもヘッドライトとして出すので、数を答えるときはこの違いを断る
- **「続くペア」**:間に何も挟まず続く 2 つのペア(例:面 k の右側と面 k+1 の右側)
- **「隣り合う」「隣接」** は、記事の文章では Yペアの形(コーナーを 1 つ挟む)を指すことがある。どちらの意味かは文脈で確かめる
- **「対面」**:記事では「偽ペア同士が対面」「対面位置に偽バーが2つ」のように、2 つの特徴が向かい合う位置関係に使う。どの位置かは、そのケースの計算の結果で確かめる
- 記事にない言葉を聞かれたら、意味を推測で決めずに確かめる

## 偽物

色は合っているように見えるが、本物ではないもの。エッジの色が、隣のコーナーの「反対側の面」のステッカーにある。

| 用語                       | 定義                                                                                                                                               | show(面 k の場合)             |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| 偽ペア                     | `E(k) = L(k+1)`(右側)または `E(k) = R(k-1)`(左側)で、同じ面のコーナーとは色が違う                                                                  | 右側なら `E(k), R(k), L(k+1)` |
| 偽バー                     | 偽ペアが両側にある(`R(k-1) = E(k) = L(k+1)`)                                                                                                       | バーと同じ 5 枚               |
| 偽ブロック                 | `E(k) = L(k+1)` かつ `E(k+1) = R(k)`(2 つの面のエッジが、互いに相手側のコーナーの色を持つ)                                                         | ブロックと同じ 4 枚           |
| 偽3x2ブロック              | 偽バーの両側に偽ブロックがある                                                                                                                     | 3x2ブロックと同じ 7 枚        |
| 偽Jブロック・偽逆Jブロック | 偽バーと、その片側の偽ブロック。左右の決め方は本物の J と同じ。偽ブロックの先も偽バーなら「2 つの偽バーが繋がった」形(C2 など)で、偽J とは呼ばない | J と同じ 6 枚                 |
| 偽ヘッドライト             | ヘッドライトと同じ 2 つのコーナーで、その面ではなく隣の面の側のステッカーが同じ色(`R(k-1) = L(k+1) ≠ E(k)`)。記事の S の段階で決めた言葉           | その 2 枚 `R(k-1), L(k+1)`    |

- 偽ヘッドライトは定義の上ではよく現れる(1 つのケースに何個もあることがある)。記事が判断に使うのは S の「ペアの色の偽ヘッドライト」など、
  条件を付けたものだけ。偽ヘッドライトがあることだけを判断の手がかりとして勧めない
- 偽ペア・偽ブロックは数が多く、記事は、そのケースの判断に使うものだけを書いている。記事が使っていない偽ペア・偽ブロックを、新しい判断の手がかりとして勧めない

## よくある取り違え

- 偽バーと偽ペア:偽バーは両側、偽ペアは片側だけ。言葉だけで決めず、計算で確かめる
- ブロックとヘッドライトの重なり:3x2ブロックの中のバーはヘッドライトではない。ヘッドライトは `L = R` でエッジが違う色のとき
- 位置の呼び方:「左上」は面にも頂点にもある。どちらかをはっきりさせる
